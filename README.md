Verificador de Maioridade

Projeto feito em PHP para praticar formulários e lógica de programação.

O sistema recebe o nome e o ano de nascimento, calcula a idade e verifica se a pessoa tem 18 anos ou mais.

* 18 anos ou mais → acesso permitido e registro salvo.
* Menos de 18 anos → acesso negado.

Tecnologias: PHP, HTML e XAMPP.
